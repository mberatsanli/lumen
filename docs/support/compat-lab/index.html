Test areas

HTML elements

Text semantics, lists, tables, forms, embedded content, navigation, template and interactive HTML elements.

CSS features

Selectors, cascade, units, box model, layout modes, backgrounds, effects, media queries and animation.

JavaScript APIs

External and inline scripts, DOM mutation, events, timers, fetch, storage, modules and canvas.

How to read differences

  • If Chrome changes text but Lumen does not, script execution is missing.
  • If a styled probe is plain in Lumen, that stylesheet or CSS feature did not apply.
  • If a control is visible but not interactive, parsing works but browser behavior is missing.
  • If a link loads but history or fragment behavior differs, navigation support is partial.
